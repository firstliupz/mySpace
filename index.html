如何新增一条规则（如三吉六秀）

所有规则通过统一注册表 Rules.register() 挂载，与绘图解耦。 新增规则只需：① 定义 id／口诀／映射；② 在 evaluate(ctx) 中依据坐向上下文返回 「标记哪些山、标注文字、断语」；③ 页面自动生成开关、自动在罗盘上标色打点。

Rules.register({
  id: 'sanjiliuxiu', name: '三吉六秀', type: '坐山',
  color: '#7c3aed', labelR: 440,
  verse: '……',
  evaluate(ctx){                 // ctx.sit / ctx.face / ctx.sitPalace …
    return [{ mountains:['艮','丙','辛'],
      label:'三吉', sub:'贵方',
      note:'……' }];
  }
});

返回数组中每项：mountains 为要标色的二十四山，label/sub 为盘面外圈标签， note 进入右侧判读结果。亦可在控制台经 window.FengShuiRules 动态试验。

盘式说明：外圈刻度为周天 360°（每山 15°，磁北为 0° 朝上）；中带八卦宫（三山一宫）；内带二十四山并叠印神煞标记； 中央为宅体示意——绿墙一侧为前（向方）：门廊、台阶、双开门；蓝墙一侧为后（坐方）：加厚实墙、高窗； 「前／后」圆形徽标随坐向转动但文字始终正立。本页为典籍口诀之速查与可视化，非堪舆实操建议。
